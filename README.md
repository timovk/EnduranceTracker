# v0.4.0 design documents

Planning material for EnduranceTracker v0.4.0, kept on its own branch so it
survives between working sessions. Nothing here is part of the app.

- `v0.4.0/BRIEF.md` — the owner's brief and the decisions made before implementation
- `v0.4.0/SYNTHESIS.md`, `v0.4.0/MAPS.json` — the map of the 0.3.2 codebase
- `v0.4.0/SPEC.md` — the binding implementation specification (revision 2)
- `v0.4.0/CRITIQUE-*.md` — the three reviews the specification answers
- `v0.4.0/work/` — the target schema, the migration and the economy model
